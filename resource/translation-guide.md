# 번역 기준

미국 소도시를 배경으로 한 서바이벌 호러의 불길하고 건조한 분위기를 유지한다.
원문에 없는 공포 묘사나 설정을 추가하지 않는다. 짧은 감탄과 침묵도 인물의 호흡으로 살린다.
대사는 인물 관계와 장면에 맞는 자연스러운 구어체로, 조사 설명은 주인공의 짧은 독백으로 쓴다.
아이템 설명과 조작 안내는 기능과 조건을 정확하게 전달한다.

퍼즐의 숫자·순서·방향·색·시간·고유명사와 반복 어휘는 그대로 보존한다.
단서가 되는 시와 수수께끼는 분위기보다 풀이 가능성을 우선한다.
서식 태그와 변수는 개수까지 일치시킨다. 의도적인 대문자 강조는 한국어 문맥으로 처리한다.
시계 숫자, 키패드 문자, 버튼 기호, 짧은 장식용 영문과 제품명은 필요에 따라 유지한다.
엔딩 이름 Leave / Rest / Live는 플레이 기록과 달성 조건의 대응을 위해 영문을 유지한다.
